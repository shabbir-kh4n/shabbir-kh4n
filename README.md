## 🎯 Featured Projects

### 🤖 [Nexora](https://github.com/shabbir-kh4n/Nexora) — Agentic AI Assistant

A planned agentic assistant for live web research, tool calling, evidence-backed answers, streaming progress, conversation history, and user-controlled memory.

**Planned stack:** React, TypeScript, Vite, Java, Spring Boot, Python, FastAPI, LangGraph, PostgreSQL, Redis, Docker, SSE

> Current status: foundation scaffold and service health checks are in place; application features are still under development.

### 🎲 RiskWise — Emotional Trading Analysis & Risk Advisory System

A paper trading platform that combines market dynamics with behavioral finance to provide AI-driven risk assessments and trading recommendations.

**Architecture highlights:** React and Angular interfaces, Node.js/Express microservices, Python FastAPI for ML inference, Socket.IO real-time data streaming, Redis caching, XGBoost prediction, SHAP explainability, Pandas/NumPy feature engineering, MySQL transactions, and MongoDB analytics.

**Key technologies:** `MERN Stack` • `Python FastAPI` • `XGBoost` • `SHAP` • `Socket.IO` • `Redis` • `Microservices`

### 🎓 [AI Career Coach](https://github.com/shabbir-kh4n/AI-Career-Coach) — AI-Powered Career Platform

A full-stack platform for resume building, tailored cover letters, technical interview practice, progress tracking, and AI-powered career guidance.

**Key technologies:** Next.js, React, Tailwind CSS, Prisma, PostgreSQL, Clerk, Google Gemini, Inngest

### 🐾 [PawFect Care](https://github.com/shabbir-kh4n/pawfect) — Pet Care & Adoption Portal

A MERN application with pet adoption workflows, real-time chat, health records, veterinary discovery, AI-powered pet name generation, and role-based authentication.

**Key technologies:** React, Vite, Node.js, Express, MongoDB, Socket.IO, JWT, Tailwind CSS, Google Gemini

### 🔄 [RegEx to NFA Visualizer](https://github.com/shabbir-kh4n/RegEx-to-NFA-Visualizer) — Automata Theory Tool

An interactive educational tool that visualizes Regular Expression to NFA conversion using Thompson’s Construction, including step-by-step animation, transition tables, statistics, and exportable diagrams.

**Live demo:** [regex-to-nfa.netlify.app](https://regex-to-nfa.netlify.app/)

**Key technologies:** HTML, CSS, JavaScript
